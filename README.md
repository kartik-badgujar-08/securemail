## 🎯 What is MailSec TLS?

Most enterprise email infrastructure relies on **opportunistic encryption (STARTTLS)** to protect communications across the internet. However, opportunistic encryption is uniquely vulnerable to silent tampering: active adversaries on the network path can strip `STARTTLS` announcements, downgrade TLS versions to vulnerable legacy protocols (TLS 1.0/1.1), or force broken ciphers—**all without triggering security alarms on the sending or receiving mail servers**.

**MailSec TLS** is an automated, **100% passive network security auditing engine**. By analyzing raw network packet captures (PCAPs), it reconstructs email conversations, audits the cryptographic strength of TLS handshakes and X.509 certificate chains, and delivers immediate risk scoring combining **deterministic compliance rules** with an **unsupervised Isolation Forest AI model**.

## ✨ Key Capabilities

### 🔍 100% Passive & Non-Disruptive
Inspects production email traffic from network taps, mirror ports, or forensic PCAPs with **zero packet injection**, **zero downtime**, and no performance impact on live mail servers.

### 🔄 STARTTLS State Machine Reconstruction
Traces the full conversation lifecycle for **SMTP, IMAP, and POP3**: captures initial plaintext commands, monitors server acknowledgments, and verifies the exact packet boundary where encryption takes over.

### 🔐 Cryptographic & Certificate Dissection
* **Handshake Auditing**: Parses ClientHello and ServerHello records to identify offered and negotiated cipher suites.
* **Forward Secrecy Verification**: Validates whether sessions use Perfect Forward Secrecy (`ECDHE`, `DHE`, `TLS 1.3`) or vulnerable static RSA key exchanges.
* **X.509 Certificate Chain Inspection**: Audits Subject/Issuer entities, Subject Alternative Names (SANs), key lengths, expiration dates, and untrusted self-signed certificates.

### 🛡️ Hybrid Threat & Vulnerability Scoring
* **Deterministic Rules Engine**: Flags cleartext credentials, legacy TLS versions (SSL 3.0, TLS 1.0/1.1), broken ciphers (3DES, RC4), and weak keys—generating an instant **0 to 100 Risk Score** and executive letter grade (`A+` to `F`).
* **Unsupervised AI Anomaly Detection**: An **Isolation Forest** model analyzes 11-dimensional cryptographic vectors to flag behavioral anomalies and provides plain-English explainability reasons for each detection.

### 📊 Instant Multi-Format Reporting
Export audit deliverables in one click:
* **Native Executive PDF**: Multi-page report with scorecards, vulnerability impact tables, and remediation guidance.
* **Printable HTML**: Self-contained executive audit view optimized for browser printing (`Ctrl + P`).
* **Structured JSON**: Machine-readable format ready for SIEM and security automation ingestion.

## ⚡ Quick Start

### 1. Launch the Platform
From the project root, run the single-command launcher:

**Windows (PowerShell / CMD):**
```cmd
run.bat
```

**Linux / macOS / Git Bash:**
```bash
./run.sh
```

The script automatically verifies dependencies, starts the backend API and frontend dashboard, and opens the application in your browser.

### 2. Access the Application
* **Frontend Web Dashboard**: [http://localhost:5173](http://localhost:5173)
* **Backend API**: [http://localhost:8000](http://localhost:8000)

### 3. Test with Sample Captures
Pre-packaged PCAP captures are available in [`backend/sample_captures/`](backend/sample_captures/):
* **`smtp_vulnerable_sample.pcap`**: Tests cleartext email exposure, legacy TLS 1.0, 3DES, and non-PFS ciphers (Triggers Critical Risk & AI Anomalies).
* **`smtp_starttls_pfs_sample.pcap`**: Tests modern hardened TLS 1.2 with ECDHE PFS and valid certificates (Passes with Grade A+).
